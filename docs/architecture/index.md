# Architecture Index

빠른 시스템 지도는 루트의 [ARCHITECTURE.md](../../ARCHITECTURE.md)를 먼저 읽습니다.

- 레이어가 무엇을 소유하는지 판단하려면 [boundaries.md](boundaries.md)를 읽습니다.
- import 가능 여부와 자동 검사를 이해하려면 [dependencies.md](dependencies.md)를 읽습니다.
- 중요한 선택의 이유를 확인하려면 [decisions](decisions/README.md)를 읽습니다.

아키텍처 변경은 코드와 문서를 함께 변경하고 필요한 경우 ADR을 추가합니다.
