# Agent Self Review

구현 후 diff를 읽고 다음 질문에 답합니다.

- 기존 동작 중 무엇이 깨질 수 있는가?
- 테스트하지 않은 성공, 실패, 경계값 경로가 있는가?
- 외부 입력이 Zod를 거치지 않고 내부로 들어오는가?
- 레이어 방향이나 feature 격리를 위반하는가?
- 기존 abstraction을 무시하거나 한 번만 쓰는 helper를 만들었는가?
- 오류가 수정 가능한 맥락을 보존하는가?
- 보안, 접근성, 하위 호환성 문제가 있는가?
- 코드 변경으로 문서가 낡아졌는가?
- 더 작은 변경으로 같은 결과를 낼 수 있는가?

발견한 문제를 수정하고 `pnpm verify`를 다시 실행합니다. 실행 결과 없이 “문제 없어 보임”으로 완료하지 않습니다.
