# Harness Engineering Bootstrap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Build the complete agent-first engineering harness defined by `Build Harness Engineering Prompt.md` for the Mannamap frontend, with one verification command and equivalent Codex and Claude Code guidance.

**Architecture:** Repository knowledge is progressively disclosed from `AGENTS.md` and `CLAUDE.md` into architecture, domain, development, reliability, security, decision, and execution-plan documents. Executable shell entrypoints delegate to package scripts; Node-based structural checks enforce architecture, documentation, and drift rules; CI and Claude Code invoke the same `pnpm verify` contract.

**Tech Stack:** Next.js 16, React 19, TypeScript 5, pnpm, Biome, ESLint, Vitest, Zod, Playwright, GitHub Actions, Claude Code project settings and skills.

## Global Constraints

- Treat the supplied harness prompt as the source of truth.
- Keep `AGENTS.md` short and navigational.
- Use progressive disclosure: map, relevant knowledge, implementation.
- Convert enforceable architecture rules into executable checks.
- Validate untrusted data at system boundaries.
- Expose `./scripts/verify` and `pnpm verify` as the complete verification loop.
- Keep Codex and Claude Code on one shared repository contract.
- Do not commit, push, or connect a remote repository.
